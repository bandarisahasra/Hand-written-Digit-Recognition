# Handwritten Digit Recognition using Machine Learning

## Project Description

This project recognizes handwritten digits (0–9) using Machine Learning.
The system is trained on a dataset of handwritten digit images and predicts which number the image represents.

## Technologies Used

* Python
* NumPy
* Matplotlib
* Scikit-learn
* Google Colab

## Dataset

This project uses the MNIST digits dataset available in Scikit-learn.

## Machine Learning Algorithm

Logistic Regression is used to train the model for digit classification.

## Project Steps

1. Import required libraries.
2. Load the digits dataset.
3. Visualize sample handwritten digits.
4. Split the dataset into training and testing data.
5. Train the Logistic Regression model.
6. Predict handwritten digits.
7. Evaluate the model using accuracy score.

## Output

The model predicts the digit (0–9) from the handwritten image.

## Example

Input: Image of handwritten digit
Output: Predicted digit (0–9)
